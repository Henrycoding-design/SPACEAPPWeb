Roadmap & Availability

v3.0 (Open-Source: Free) Legacy is the basic version of SPACEAPP and will remain available until December 2025 before being retired in favor of the upcoming v5.x releases.

v4.0 (Open-Source: Charged) Legacy is the plus version of SPACEAPP, with more features and improvements.

v4.2 (Open-Source: Charged) Legacy is the Vietnam-supported-only version of SPACEAPP, with all the features of v4.0 plus some bug fixes and performance improvements.

v5.0 (Closed-Source) Stable : higher reliability and adaptability — cleaner logs, fewer API interruptions, and a self-updating satellite list and user location for better accuracy.

v5.5.x (Closed-Source) Stable introduces a refined system architecture with smarter API usage, pre-indexed cloud-assisted satellite search, orbital path prediction, and a dedicated x64 installer. Designed for long-term reliability, scalability, and improved analytical tracking.

v5.6.x (Closed-Source) Stable Best marks a milestone structural leap with the delivery of the first official macOS environment package alongside the classic Windows pipeline. Features immersive interactive 3D spacecraft structural inspectors, AI-assisted mission summaries, full orbital lifespan metrics, coverage footprint estimators, and an updated RAG-driven background synchronization framework.
